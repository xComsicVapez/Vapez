# "Any version" edition: only mods that work with an unmodded client, behind a
# Velocity proxy running ViaVersion/ViaBackwards/ViaRewind so Minecraft 1.8 up to
# the newest release can join. Install with:  EDITION=any-version ./setup.sh
# Every mod that adds blocks, items, mobs or client screens is left out, because
# a vanilla client can't join a server that has them.

# --- Version bridging (plugins for the Velocity proxy in front of the server) ---
viaversion       @velocity   # newer clients
viabackwards     @velocity   # older clients (down to 1.9)
viarewind        @velocity   # 1.7/1.8 clients
fabricproxy-lite             # lets the proxy forward real player UUIDs/skins to the server
