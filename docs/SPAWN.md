# Spawn — Aether Citadel

The spawn megastructure is **original**. It is not imported from PlanetMinecraft, BuildPaste, or any commercial SMP.

Do not drop copyrighted schematics into `pack/schematics/`. If you commission a builder, use **your** license; FAWE can import `.schem` with:

```
//schem load vapez-citadel
//paste -a
```

## How it is built

On first overworld load, `VapezCore` queues a chunked builder (`CitadelBuilder`):

- Flattens a 17×17 chunk pad to Y=64
- Concentric rings (deepslate, amethyst, blackstone, quartz, copper)
- 56-block walls, four gate arches, corner lightning-rod towers
- Cardinal market streets, west **Aetherforge** sanctum, north crate pavilion, south leaderboard terrace
- Moat, soul lighting, central lodestone + beacon
- World spawn at `0.5, 67, 0.5`
- World PDC `vapez:citadel_built`

Rebuild: `/vapez buildspawn` (ops).

A smaller FAWE schematic (`pack/schematics/vapez-citadel.schem`) of the inner plaza is generated by `scripts/generate_assets.py` if you prefer schematic paste in a different world.

## Protection

Centered on **world spawn** (so a transferred world is covered, not only 0,0).

1. **WorldGuard** region `spawn` in `pack/plugins/WorldGuard/worlds/world/regions.yml` (invincible, no break, no mobs, no PvP)
2. **VapezCore fallback guard** — cancels break/place, **all player damage/death**, hunger, explosions, fire, and hostile mobs inside `spawn.protection-radius` (default 128) unless `vapez.admin`. Existing hostiles are purged.

Vanilla `spawn-protection` is **0** so FAWE/WorldEdit ops are not fighting vanilla.

Remote look (phone, no Minecraft client): [REMOTE.md](REMOTE.md). Console: `/vapez spawnstatus`.

## Transferred worlds

If the spawn chunk already has inhabited time, the Citadel **will not flatten** your imported map. Signature on the dashboard will be `CUSTOM`. Force the original citadel only with `/vapez buildspawn`.

## Optional: third-party builds

If you later import a **licensed** schematic with FAWE:

1. `/vapez` will not overwrite if `citadel_built` is set — `/vapez buildspawn` force-rebuilds the original citadel, so don’t run that after a custom import
2. Re-fit WorldGuard `min`/`max` to the new footprint
3. Move hologram locations in DecentHolograms
4. Keep the forge NPC near whatever altar you build
