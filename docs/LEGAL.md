## What this repository is

An original server pack and plugin (`VapezCore`) that implements a high-performance **economy Survival Multiplayer** in the same *genre* as many public SMPs.

## Original work in this repo

- `plugin/` VapezCore source

- Aether Citadel builder + generated schematic

## Custom models and Bedrock

The Java and Bedrock packs contain **original 16×16 icons** generated by `scripts/generate_assets.py`. They are not Mojang or DonutSMP art.

## If you need a premium plugin

Buy it. Configure it to sit beside VapezCore. Disable overlapping VapezCore modules in `plugins/VapezCore/config.yml` (`shop.enabled`, `auction.enabled`, …) rather than running two auction houses.
