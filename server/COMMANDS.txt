PLAY.COSMICPIXEL.ORG (lifesteal2) - COMMAND LIST
================================================
<x> = required, [x] = optional, a|b = pick one.
"Everyone" commands work for every player. "Owner / ops" commands need op
(run "op <name>" from the server console) unless noted.


EVERYONE - TELEPORTING
----------------------
/spawn                      Go to spawn
/rtp   (/randomteleport)    Random teleport about 1000 blocks from spawn (30 s cooldown)
/tpa <player>               Ask to teleport to a player
/tpahere <player>           Ask a player to teleport to you
/tpaccept [player]          Accept a teleport request (name only needed with 2+ requests)
/tpdeny [player]            Deny a teleport request
/tpcancel                   Cancel the request you sent
/back                       Go back to where you last teleported from
/warp <name>  /warp list    Use a warp set by an op

EVERYONE - HOMES (1 home per player)
------------------------------------
/sethome [name]             Set a home where you stand (default name "home")
/home <name>                Teleport to a home
/homes                      List your homes
/delhome [name]             Delete a home
(Long forms also work: /home set|tp|delete|list <name>)

EVERYONE - ECONOMY AND SHOPS
----------------------------
/shop                       Open the shop (selling only, buying is turned off)
/sellhand [all|<amount>]    Sell the item in your hand
/worth [all|<item>]         See what an item sells for
/bal [player]  /balance     Check money
/baltop  /money top         Richest players
/pay <player> <amount>      Send money
/ah                         Auction house (/ah sell <price>, /ah buy, /ah claim, /ah cancel)
/enchants  (/ce)            Custom enchant menu: spend XP levels on random enchant books
                            Common 5 lvls, Epic 15, Legendary 25, Exclusive 40
                            (The "Custom Enchants" villager at spawn also sells max-level books)

EVERYONE - LIFESTEAL
--------------------
/withdraw <amount>          Turn hearts into Heart items (needs at least 1 heart crystal first)
Heart recipe (crafting table):
    Diamond Block | Gold Block      | Diamond Block
    Gold Block    | Netherite Ingot | Gold Block
    Diamond Block | Gold Block      | Diamond Block
Right-click a Heart to use it.

EVERYONE - HANDY STUFF
----------------------
/enderchest                 Open your ender chest anywhere
/workbench                  Portable crafting table
/stonecutter                Portable stonecutter
/grindstone                 Portable grindstone
/wastebin                   Trash can
/afk                        Mark yourself AFK
/suicide                    Kill yourself
/rules                      Server rules
/gametime                   Current in-game time
/msg <player> <message>     Private message (also /tell, /w)
/me <action>                Action message
/list                       Who's online
/simpleskills togglehud     Show/hide the skills HUD
/simpleskills leaderboard   Skills leaderboard
/voicechat                  Simple Voice Chat (needs the client mod; press V in-game)

Rules of the world: spawn has no fall damage and no PvP. Death drops can be
picked up by anyone. Bedrock players join on port 19132.

FROM THE SERVER MACHINE (SSH as cosmic, not in-game)
----------------------------------------------------
mc lifesteal2 start          Start the server
mc lifesteal2 stop           Save and stop
mc lifesteal2 restart [secs] Warn players, save, restart
mc lifesteal2 console        Open the console (leave with Ctrl+B then D)
mc lifesteal2 cmd <command>  Run a console command, e.g. mc lifesteal2 cmd op xCosmicVapez
mc lifesteal2 status
