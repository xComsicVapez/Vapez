COSMICPIXEL WEB STORE - SETUP AND OWNER GUIDE
=============================================

The store is already installed and running. It works right now through a temporary link. Part 1 is how
players use it, part 2 gives it a permanent address (store.cosmicpixel.org), and the rest covers prices,
starting and stopping, and fixing problems.


1. HOW PLAYERS USE IT
---------------------
1. Join play.cosmicpixel.org and type  /store  in chat.
2. Chat shows a 6-letter code (works once, for 10 minutes) and a link. Click the link (or type it in a browser).
3. Type the code into "Sign in" on the website.
4. Buy kits or supplies, rent a spawn plot, or revive a friend with in-game money (the same balance as /bal),
   or buy kits and supplies with a card once card payments are on (part 7). Items appear in your inventory
   right away if you are online, otherwise the next time you join.
5. Each kit or supply has a small chance (1-4%) of a bonus heart that goes past the 20 heart limit (max 5 extra).

Out of hearts:
- You get banned and the ban screen shows the date of your free automatic revive (3 days later), the store link
  and an 8-letter revive code.
- Wait for the free revive, or sign in on the store with that 8-letter code and pay for a revive from your own
  balance. A friend can also sign in with their own /store code and buy the revive for you on the "Revives" page.
- Revived players come back at spawn with 10 hearts. Bonus hearts are lost when you are eliminated.

Spawn plots (the 8 diamond domes, or whatever areas you set with /plot admin setarea):
- Rent one on the "Spawn plots" page ($2,500 a week, 1 to 4 weeks at a time, one plot per player).
- In game: /plot shows which plot and until when, /plot home teleports you there, /plot sethome changes that spot.
- Inside your dome only you can build and break, no mining fatigue, nobody else opens your chests.
- When the rental runs out you get 1 more day to renew (on the same page) before your blocks are removed.


2. GIVE THE STORE A PERMANENT ADDRESS (do this once, about 2 minutes)
---------------------------------------------------------------------
Right now the store uses a free "quick tunnel" with a random address like
https://gage-accordingly-feed-soil.trycloudflare.com. It works, but the address changes whenever the tunnel or
the VM restarts. (The store updates the /store link and ban messages by itself, so players can always find
it in game, but links posted on Discord stop working.) The fix is the store's own Cloudflare tunnel at
https://store.cosmicpixel.org :

a) On the VM (ssh cosmic@crazycraft-vm) run:
       cloudflared tunnel login
   It prints a link. Open it on any computer, log in to Cloudflare with the account that owns
   cosmicpixel.org, click  cosmicpixel.org  and then  Authorize. Leave the command running until it says
   it saved the certificate (~/.cloudflared/cert.pem).
b) Then run:
       ~/server-tools/store-tunnel-setup.sh
   It creates the "cosmic-store" tunnel and the store.cosmicpixel.org DNS record, sets "public_url" in
   ~/lifesteal2/config/web-store.json, swaps the quick tunnel for the new one and restarts the store.
   "mc lifesteal2 start" keeps starting the new tunnel after every reboot.
c) Open https://store.cosmicpixel.org, and type /store in game: the link should be the new address.

If store.cosmicpixel.org already exists in Cloudflare DNS the script stops and tells you; delete that record
in the Cloudflare dashboard (cosmicpixel.org > DNS) and run it again. Nothing about the existing tunnel for
crazy.cosmicpixel.org changes.

Security: the store only listens on 127.0.0.1 (it can't be reached except through Cloudflare), sign-ins are
one-time codes made in game, there are no passwords to steal, and only cosmic-store's op-only RCON commands
can touch money. Don't forward port 8080 on the router; Cloudflare does the work.


3. CHANGE PRICES, KITS AND RULES
--------------------------------
Kits and supplies: ~/server-tools/web-store/catalog.json  (also in the repo: server/web-store/catalog.json)
    "price"           dollars of in-game money
    "usd"             card price in real dollars (part 7); leave it out for in-game money only
    "cooldown_hours"  how often one player can buy it (0 = any time)
    "heart_chance"    percent chance of a bonus heart
    "items"           [item, count] pairs, max 64 per line; enchanted items look like
                      "iron_sword[enchantments={sharpness:2}]"
  Changes show up on the website immediately; no restart needed. Check your edit is valid JSON first:
      python3 -m json.tool ~/server-tools/web-store/catalog.json > /dev/null && echo OK

Everything else: ~/lifesteal2/config/web-store.json, then restart the store (tmux kill-session -t web-store;
~/server-tools/mc lifesteal2 start):
    "revive_price"         5000
    "revive_wait_days"     3      days until the free automatic revive
    "plot_price_per_week"  2500
    "plot_max_weeks"       4
    "public_url"           see part 2
    "ignore_players"       accounts the store never handles eliminations for (the AI bots)
  Max bonus hearts: "maxBonusHearts" in ~/lifesteal2/config/cosmic-store.json (needs a server restart).

Current prices (Oct 16): Starter $250, Farmer $150, Builder $300, Miner $400, Warrior $900,
Food Crate $60, Torch Bundle $25, Iron Crate $250, XP Bottles $150, Revive $5,000, Plot $2,500/week.


4. START, STOP, CHECK
---------------------
    ~/server-tools/mc lifesteal2 status    shows "web store" and "store tunnel" (running/stopped)
    ~/server-tools/mc lifesteal2 start     starts anything that is stopped (also runs at boot)
    tmux attach -t web-store               watch the store live (detach: Ctrl+B then D)
    tail -f ~/lifesteal2/logs/web-store.log    every login, purchase, delivery, revive and refund
Data files (don't edit while the store runs): ~/lifesteal2/config/web-store/
    purchases.jsonl     every purchase and refund (one line each)
    deliveries.json     items waiting for a player to come online
    eliminations.json   who is out of hearts, their revive code and free revive date
    cooldowns.json      kit cooldowns


5. ADMIN COMMANDS (in game as op, or the server console)
--------------------------------------------------------
/plot admin rent <plot 1-8> <uuid> <name> <days>   give someone a plot for free
/plot admin evict <plot>      end a rental (their blocks are removed after the 1 day grace)
/plot admin clear <plot>      free a plot right now and remove its blocks
/plot admin list              all plots with their corners
/plot admin setarea <id> <x1 y1 z1> <x2 y2 z2> [name]   add a plot or move/resize one (see below)
/plot admin remove <id>       delete a plot nobody rents

Setting the shop areas (rentable plots) at spawn:
  1. Stand at one corner of the area (floor level) and press F3 to read your block coordinates, or look at
     the corner block: when you type the command, Tab fills in the block you are looking at.
  2. Do the same for the opposite corner, at the top (include the space above the floor that renters may
     build in).
  3. Type, for example:   /plot admin setarea 9 300 100 -20 312 115 -8 Market Stall 9
     The id is the plot number on the website; use a new number to add a plot, or an existing one to move
     or resize it (a rented plot keeps its renter). Plots can't overlap.
  4. /plot admin list to check. The website and /plot show the new plot right away.
  Plots should be inside spawn: there, everyone else is blocked from building, and only the renter can build
  and break their own blocks inside the plot.
/revive <player>              revive someone for free
/cosmicstore balance <uuid>   /cosmicstore refund <uuid> <amount>   (refund = give money back)
/cosmicstore bonushearts get|add|reset <uuid> [n]
Find a player's uuid: /list uuids  (online) or ~/lifesteal2/usercache.json.


6. PROBLEMS
-----------
"That code is wrong, used or expired"   Type /store again for a fresh code (each code works once, 10 minutes).
Website doesn't load                    mc lifesteal2 status; if the store or tunnel says stopped, run
                                        mc lifesteal2 start. With the quick tunnel the address may have changed:
                                        type /store in game for the current link.
"the server did not answer"             The game server was restarting. Check /bal before buying again;
                                        a charge is never sent twice.
Bought something but got nothing        Items arrive when you are online; check the log for "DELIVERED".
                                        If something failed after paying, the store refunds automatically
                                        ("REFUND" in the log).
Player says the revive didn't work      Look for "REVIVE" or "AUTO REVIVE failed" in the log; /revive <player> fixes it.


7. CARD PAYMENTS (REAL MONEY) WITH STRIPE
-----------------------------------------
Kits and supplies can also be bought with a card. Stripe hosts the payment page (cards, Apple Pay, Google
Pay), so card numbers never touch your server. Card purchases have no cooldown and still roll the bonus heart.
Until a Stripe key is set the card buttons are hidden and nothing changes.

a) Make an account at https://dashboard.stripe.com/register and finish "Activate payments" (business details
   and the bank account payouts go to). Stripe pays out to you minus about 2.9% + 30c per payment.
b) Test first: in the Stripe dashboard turn on "Test mode", open Developers > API keys and copy the
   "Secret key" (starts with sk_test_). Treat it like a password: it only goes in the file below.
c) On the VM:
       nano ~/lifesteal2/config/web-store.json
   add a line   "stripe_secret_key": "sk_test_...",   (keep the commas valid), save, then restart the store:
       kill $(pgrep -f "^python3 /home/cosmic/server-tools/web_store.py")
   (it starts again by itself within 5 seconds). Cards need the permanent address from part 2 first.
d) Sign in on the store, press "Buy with card" and pay with the test card 4242 4242 4242 4242, any future
   date, any CVC. You get sent back to the store, the kit is delivered, and "CARD ORDER" shows in the log.
e) When that works, repeat c) with the live key (sk_live_) from the dashboard with Test mode off.

Card prices are the "usd" field of each product in ~/server-tools/web-store/catalog.json (remove "usd" to sell
a product for in-game money only). Current card prices: Starter $2.99, Farmer $1.99, Builder $2.99,
Miner $3.99, Warrior $6.99, Food $0.99, Torches $0.99, Iron $1.99, XP $1.49.
Every paid order is in ~/lifesteal2/config/web-store/card-orders.json and the Stripe dashboard (Payments).
Refunds: Stripe dashboard > Payments > the payment > Refund (the store does not take the items back).
No webhook is needed: the store asks Stripe about each payment when the buyer comes back, and checks for
paid orders every minute in case someone closes the page early.

Important - Mojang's rules: the Minecraft EULA and Mojang's server guidelines do not allow selling gameplay
advantages (kits, gear, hearts, revives) for real money; only cosmetics, server access and donation ranks
without advantages are allowed. Many servers sell kits anyway, but Mojang can block servers that break these
rules so they can't be joined. Selling kits for real money is your decision and your risk. A safer option is
to give "usd" prices only to cosmetic products (they can be added to the catalog like any other product).
